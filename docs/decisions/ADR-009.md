# ADR-009: F1 tier auto-pause resolution

## Status

Accepted

## Context

The logic app to keep the api alive simulates always on F1 tier, however there's a cap of 100 000 vCore seconds per free offer database. This means the database is online for around 2 days if always on before running out of vCore seconds and deactivating.

## Decision

Switch to DTU-based on a Basic tier for 7.15 USD per month at a fixed rate.

## Alternatives

1. Increasing the logic app interval would result in the database (serverless) auto-pausing anyway.
2. Setting dedicated pause periods like overnight will still result in the database running out of vCore seconds just at a slower pace. Still not enough to last a month.

## Consequences

A fee is required to keep the api alive throughout the month. Acceptable since it's just 7.15 USD fixed per month, about 116.15 ZAR.
