# ADR-004: Register entity join tables on DbContext

## Context

Entity join tables like `ExperienceSkill`, `EducationSkill`, etc. are not registered on DB meaning they cannot be persisted. This makes linking skills to, for example, `Experience` and `Education` impossible.

## Decision

All entity join tables must be registered on `DbContext`, this will enable persistence for those tables.

## Alternatives

Use the existing `Skill` table to record skills for each section: this will result in duplication of `Skill` records due to reuse across different sections.

## Consequences

Adds more registration entries to `DbContext`, acceptable consequence.
