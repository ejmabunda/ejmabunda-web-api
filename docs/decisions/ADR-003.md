# ADR-003

## Status

Accepted

## Context

The API currently implements full CRUD operations on the profile controller. By design, all `GET` operations are public, and the rest are gated behind JWT authentication. For a single user API, this is an efficient way to add a security later without adding unnecessary complexity. Identity authentication is overkill for this project, however it is something I can consider on a multi-user project.

## Decision

The API is gated by JWT authentication instead of Identity-based authentication like Microsoft Entra Id.

## Alternatives

Identity-based authentication Microsoft's Entra ID offer an identity and security layer that provide better support for multi-user projects. A better alternative that would unfortunately add unnecessary complexity to a simple single user API.

## Consequences

Converting to a multi-user project would require architectural changes, an acceptable consequence.
