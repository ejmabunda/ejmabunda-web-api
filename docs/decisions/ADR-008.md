# ADR-008: Replace keep-alive workflow with Azure Logic App

## Status

Accepted, Supersedes [ADR-007](ADR-007.md)

## Context

`keep-alive` workflow's flaw is actually worse than GitHub suggests, cron jobs can sit in a queue for hours - 4 - 5 hours in my case - and occasionally dropped from the queue entirely. This defeats the purpose of the workflow. Only 3 ran on schedule yesterday and they are hours apart.

## Decision

Setup an Azure Logic App to ping the api every 15 minutes. This is free for the first 4000 executions per month per subscription.

## Alternatives

External/third-party tools like cron-job.org and UptimeRobot are free, and fire on time. These are rejected in favor of Azure native tools since building on Azure is the goal of this project.

## Consequences

This is a new concept, so there's a learning curve and more room to make mistakes. An acceptable consequence that supports learning.
